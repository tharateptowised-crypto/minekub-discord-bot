# ⛏️ MINEKUB Discord Setup

ตั้งค่า Discord MINEKUB โดยไม่ต้องเขียนโค้ด: สร้างยศสมาชิกพื้นฐาน ห้องต้อนรับ กฎ และข้อความรับยศด้วย GitHub Actions

## วิธีใช้งาน (ครั้งแรก)

1. เพิ่ม `MINEKUB Bot` เข้าเซิร์ฟเวอร์ Discord ชื่อ **MINEKUB** (ทำแล้ว)
2. ตรวจสอบว่าบอทมีสิทธิ์ **Manage Channels**, **Manage Roles**, **View Channels**, **Send Messages**, **Read Message History**, **Embed Links** และยศบอทอยู่สูงกว่ายศสมาชิก
3. เข้า Repository นี้ > **Settings → Secrets and variables → Actions → New repository secret** แล้วเพิ่ม:
   - `DISCORD_BOT_TOKEN` = Bot Token จาก Discord Developer Portal → Bot (ห้ามส่ง token ในแชทหรือใส่ในไฟล์)
   - `DISCORD_GUILD_ID` = Server ID ของ MINEKUB (เปิด User Settings → Advanced → Developer Mode แล้วคลิกขวาที่ไอคอนเซิร์ฟเวอร์ → Copy Server ID)
4. ไปที่ **Actions → Setup MINEKUB Discord → Run workflow**
5. รันครั้งแรกโดยตั้ง `dry_run = true` เพื่อตรวจสอบรายการที่บอท *จะ* ทำ (ไม่มีการแก้ไข Discord)
6. ถ้ารายการถูกต้อง ให้รันอีกครั้งโดยตั้ง `dry_run = false` เพื่อสร้างสิ่งที่ขาดและโพสต์ข้อความ

## ทำอะไรบ้าง

- ตรวจสอบว่า Server ID ตรงกับเซิร์ฟเวอร์ชื่อ MINEKUB ก่อนทำงาน
- สร้างยศ `✅ สมาชิก` ถ้ายังไม่มี (หรือใช้ยศ `สมาชิก` ที่มีอยู่แล้ว) โดย **ไม่ให้สิทธิ์แอดมิน**
- ตรวจสอบห้องเดิมก่อนสร้าง `👋・ยินดีต้อนรับ`, `📜・กฎเซิร์ฟเวอร์`, `✅・รับยศสมาชิก`, `🎭・เลือกรับยศ`
- ส่งข้อความภาษาไทยที่เตรียมไว้ เมื่อไม่พบข้อความหัวข้อเดียวกันอยู่แล้ว
- ไม่ลบ ไม่ย้าย และไม่แก้ไขห้องเดิมหรือยศเดิม และไม่แตะห้องอื่น

## ข้อสำคัญ: การกดรับยศ

GitHub Actions นี้เป็น **เครื่องมือตั้งค่าแบบรันครั้งเดียว** ไม่ใช่โฮสต์บอทออนไลน์ตลอดเวลา
จึง **ยังไม่มีปุ่มรับยศที่กดแล้วมอบยศได้ทันที** หลังรัน setup.
หากต้องการให้สมาชิกเลือกรับยศอัตโนมัติแบบไม่ต้องโฮสต์บอท ให้เปิด Community และใช้ **Discord Onboarding**
(ตั้ง Prompt สำหรับเลือกรับ `✅ สมาชิก` และบทบาทอื่น) หรือเชื่อมโฮสต์บอทออนไลน์ในขั้นถัดไป
**อย่าเพิ่งประกาศว่าปุ่มรับยศใช้งานได้ ก่อนตั้งค่าระบบรับยศจริง**

## ความปลอดภัย

- เก็บ Token ใน GitHub Actions Secrets เท่านั้น ไม่ใส่ในโค้ดหรือ README
- ห้ามมอบ `Administrator` ให้บอทถ้าไม่จำเป็น
- Workflow ทำงานเมื่อกด Run เท่านั้น ไม่รันอัตโนมัติ
- ใช้ `dry_run = true` ก่อนดำเนินการจริงทุกครั้ง
- หากบอทเพิ่มยศไม่ได้ ให้ตรวจสอบลำดับยศใน Server Settings → Roles
