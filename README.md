# ⛏️ MINEKUB Discord Setup 2.0

ระบบตั้งค่าห้องต้อนรับ กฎเซิร์ฟเวอร์ จุดรับยศสมาชิก และยศ Minecraft ด้วย GitHub Actions

## ใช้งาน
1. เก็บ `DISCORD_BOT_TOKEN` และ `DISCORD_GUILD_ID` ไว้ใน GitHub Actions Secrets เท่านั้น
2. เปิด Actions → Setup MINEKUB Discord → Run workflow
3. รัน `dry_run = true` เพื่อพรีวิวก่อน (ไม่แก้ไข Discord)
4. ตรวจรายการจาก log แล้วรัน `dry_run = false` เพื่ออัปเดตจริง

## สิ่งที่ระบบจัดการ
- ใช้ห้องเดิมก่อนเสมอ สร้างเฉพาะห้องที่ไม่มี: ยินดีต้อนรับ กฎ รับยศสมาชิก เลือกรับยศ
- ข้อความภาษาไทย: ต้อนรับ กฎ 8 ข้อ วิธีรับยศ และวิธีเลือกสายการเล่น
- ยศพื้นฐาน `✅ สมาชิก` และยศเสริม Java, Bedrock, Builder, Redstone, Explorer, Survival
- อัปเดตเฉพาะข้อความที่ MINEKUB Bot เคยส่งไว้ หากพบหัวข้อเดียวกัน ป้องกันข้อความซ้ำ
- ไม่ลบหรือย้ายห้อง ไม่ลบยศ ไม่แก้สิทธิ์ห้องเดิม และไม่แก้ไขข้อความของคนอื่น

## จุดรับยศอัตโนมัติ
GitHub Actions ทำงานชั่วคราวตอนกด Run เท่านั้น ไม่ได้ทำให้บอทออนไลน์ตลอดเวลา ดังนั้นปุ่มรับยศแบบกดแล้วได้รับทันที **ยังไม่ทำงาน** จากสคริปต์นี้
แนะนำให้ใช้ Discord Community Onboarding:
- เปิด Community ใน Server Settings
- ไปที่ Onboarding แล้วสร้างตัวเลือกรับยศ `✅ สมาชิก`
- เพิ่มตัวเลือก Java / Bedrock และ Builder / Redstone / Explorer / Survival
- ตรวจสอบการเข้าถึงห้องก่อนเปิดใช้งาน

## ความปลอดภัย
- อย่าส่ง Bot Token ในข้อความหรือใส่ใน Repository
- ห้ามมอบสิทธิ์ Administrator ให้สมาชิกทั่วไป
- ควรวางยศบอทให้สูงกว่ายศที่จะสร้าง
- ตรวจสอบผล Dry Run ก่อน Apply ทุกครั้ง
